# NereidVLA website — archived

The merged project homepage has moved to the original research repository. This repository is retained as a historical snapshot, and its GitHub Pages publication has been disabled.

- **Official homepage:** https://sky-zhu-91.github.io/NereidVLA/
- **Active repository:** https://github.com/SKY-Zhu-91/NereidVLA
- **Paper:** https://arxiv.org/abs/2611.24864

All future website changes should be made in `SKY-Zhu-91/NereidVLA`:

- `index.html`: content, authors, links, and citation.
- `css/style.css`: visual styling and responsive layout.
- `js/app.js`: interactive components.
- `js/research-data.js`: numerical research results.
- `assets/`: images and font.

The original repository's `main` branch publishes the official homepage. Do not re-enable Pages in this archived repository.

Research content and figures are from the authors' arXiv paper. Manrope is distributed under the SIL Open Font License; see `docs/assets/OFL-Manrope.txt` in this historical snapshot.
